# CoXlab open source

Source code of the open source software in CoXlab products, published as the
GNU GPL, LGPL, AGPL and similar licenses require.

## IOTOWN

The open source notice of IOTOWN (About → Open Source Licenses, at
`https://<server>/oss/`) lists every component with its version. The releases
named `iotown-sources-<date>` hold the source code of the components that ship
as files, such as Grafana, Grafana Loki, libvips and BusyBox. Each release
covers one set of versions: use the release whose notes list the versions in
your notice. For the Linux distribution packages inside the images (Alpine,
Debian, Ubuntu), the notice links the source of each exact version.

## Requests

To request the source code on a physical medium, write to support@coxlab.kr
with the product name and version, as described in the written offer of the
notice.
